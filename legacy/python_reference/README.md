# Archived Python reference

This directory contains the Python reconstruction that previously occupied the
top level of the repository. It is preserved for comparison and provenance
only. The maintained implementation of the undergraduate project is the
Fortran 90 module in [`../../fortran/brillouin90.f90`](../../fortran/brillouin90.f90).

The archived files are not used by the Makefile or the GitHub Actions workflow.
They may still be useful for plotting the existing PNG figures or checking the
same geometric invariants with NumPy.
