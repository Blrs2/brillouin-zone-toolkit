# Documentation artifacts

`figures/` and `summary.json` are visual artifacts from the project. The
maintained numerical implementation is now the Fortran 90 module in
`../fortran/brillouin90.f90`; the former Python figure/reproduction code lives
under `../legacy/python_reference/`.

The source PDF is intentionally kept outside the public repository until
redistribution rights are confirmed. The original remains available as
`../BrilloinZones_IC.pdf` in the supplied local archive. The repository's MIT
license does not relicense that document.
